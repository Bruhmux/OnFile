# Rules

## Start of Game

Players are organized into a random order.
First player is chosen to start. They choose 1 suspect file of their choice.
From this file, the player chooses 2 of the following pieces of information.

- Suspect
- Location
- Weapon

The next player does the same on a different file that has not yet been chosen.
This goes until it all players have chosen a file.

> [!IMPORTANT]
> Players must keep information to themselves.

Each player gets a logic grid to record any information they get or deduce.

### Grid Example

I chose a file for **suspect** and **weapon** and learned that Suspect.2 had Weapon.3
This means I would know that no other **suspect** had that **weapon**,
and that **weapon** was with no other **suspect**

| Item.1 |  | X |  |  |

## Main

After all files are chosen, the players take turns revealing pieces of information on the public grid.

- When an `X` is placed, the player receives a `Discovery` and gets some to choose more
information based on the rules of the discovery they received.
- When an `O` is placed, the player gets to choose *2* different files and any *2* pieces of information, including verdicts.

> [!WARNING]
> If a player does not have any information that is not publicly available,
the next player may donate a piece of information that the receiving player
must immediately reveal

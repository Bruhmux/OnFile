# 🏰 Crypts n' Clues: Visual Guide

Welcome, Investigator. Use this guide to master the art of deduction in the town of Crypts n' Clues.

---

## 🎭 The Objective
**Be the first to solve the mystery:**
- 👤 **Who** is the Killer?
- 🗡️ **What** was the Weapon?
- 📍 **Where** did it happen?

Only the first player to correctly solve the case gets paid. Everyone else stays in the shadows.

---

## 📜 Phase 1: The Investigation (Setup)

1. **Turn Order:** Players are randomized. 🎲
2. **File Selection:** Each player chooses **one** unique Suspect File.
3. **Intel:** Choose **two** pieces of information from your file:
   - 👤 Suspect | 🗡️ Weapon | 📍 Location

> [!IMPORTANT]
> Keep your findings secret! Use your **Private Logic Grid**.

### 📉 How to Use Your Grid
If you find that **Suspect 2** used **Weapon 3**:

| | 👤 Susp.1 | 👤 Susp.2 | 👤 Susp.3 | 👤 Susp.4 |
| :--- | :---: | :---: | :---: | :---: |
| 🗡️ **Wpn.1** | | ❌ | | |
| 🗡️ **Wpn.2** | | ❌ | | |
| 🗡️ **Wpn.3** | ❌ | **⭕** | ❌ | ❌ |
| 🗡️ **Wpn.4** | | ❌ | | |

*Legend: ⭕ = Match Found | ❌ = Impossible*

---

## ⚔️ Phase 2: The Trial (Main Game)

Players take turns revealing information on the **Public Grid**.

### 🔍 Discovery Rewards
When you place a mark on the public board, you earn bonuses:

| Action | Result | Bonus 🎁 |
| :--- | :--- | :--- |
| **Place ❌** | **Mismatch** | Receive a `Discovery` (extra info choice). |
| **Place ⭕** | **Match!** | Choose **2** files + **2** pieces of info (any type). |

---

## 🆘 Running Out of Clues?
If you have no secret info left to share:

1. **Donation:** A player can give you info. You **must** reveal it immediately.
2. **Penalty:** If no one shares, you get **one random clue** but **lose your turn**. ⏳

---

## 🏆 The Verdict
When you are certain, call for a **Verdict**. 
- **Correct:** You win the gold! 💰
- **Incorrect:** You are exiled from the investigation. 🚫
